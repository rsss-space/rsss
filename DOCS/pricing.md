# Pricing

## Free Version

* Can use the web app online
* No limit to number of feeds stored
* includes a "share to Bluesky" button on each feed
* includes a social network -- you can see the feeds of users you follow,
  all your following activity (followed feeds) is public.
* Can read the comments only (cannot post comments)


## Paid version

* Offline-first mode (the app has settings to control which feeds are cached
  and readable offline).
* You are able to make some feeds _private_ -- meaning that they are not
  posted to your social feed
* You are able to comment on your feeds and other's feeds. It includes a
  comment UX similar to Bluesky
